TouchFS User Flows

All possible user interactions mapped out

🚀
First Launch (New User)
Onboarding
  1. App opens → "Checking..." → no key found
  2. Welcome screen → tap Continue
  3. Set password → enter + confirm → key stored in Keychain
  4. Add first file → file picker → file sealed
  5. "Open TouchFS" → Main view + mount starts
👤
First Launch (CLI User)
Onboarding
  1. App opens → Touch ID → key found → Main view
  2. Empty file list (no config yet)
  3. "Find Sealed Files" → pick directory → scan
  4. Select files to import → added to list
  5. Mount starts automatically
☀️
Normal Launch
Core
  1. App opens → Touch ID → Main view
  2. Mount starts with all managed files
  3. Activity log populates as files are accessed
➕
Add File
Core
  1. Click "+" or "Add File"
  2. File picker → select file
  3. File sealed (encrypted in place)
  4. Appears in managed list
  5. Mount restarts to include new file
🖱️
Add File (Drag & Drop)
Core
  1. Drag file onto app window
  2. File sealed
  3. Appears in managed list
  4. Mount restarts
➖
Remove File
Core
  1. Right-click file → "Remove Protection"
  2. File unsealed (decrypted to plaintext)
  3. Removed from managed list
  4. Mount restarts without that file
🔍
Find Sealed Files
Core
  1. Click "Find Sealed Files"
  2. Directory picker → choose scope
  3. Progress indicator while scanning
  4. Results shown → toggle which to import
  5. "Add N Files" → mount restarts
👁️
File Access (External App)
Core
  1. External app reads a sealed file
  2. Touch ID prompt (500ms cache per file)
  3. Authenticated → decrypted content served
  4. Logged in Activity: file, time, "Opened"
  5. If denied → blocked, logged as "Denied"
✏️
File Modified (External App)
Core
  1. External app writes to a mounted file
  2. On close → content re-encrypted
  3. Logged as "Modified" in Activity
🪟
Close Window
Lifecycle
  1. Close window (red X or Cmd+W)
  2. App keeps running in menu bar
  3. Mount stays active — files protected
  4. Menu bar → "Open TouchFS" to reopen
🚪
Quit App
Lifecycle
  1. Cmd+Q or menu bar → "Quit"
  2. Mount receives SIGINT → clean shutdown
  3. All symlinks restored to sealed files
  4. App exits
💥
Crash / Force Quit
Error
  1. Mount process dies without cleanup
  2. Sealed files left as broken symlinks
  3. Next launch → auto-recovers from xattrs
  4. Files restored to sealed state
🔑
Change Password
Settings
  1. Settings → "Change Password"
  2. Enter new password + confirm
  3. App unseals all files with old key
  4. Sets new key → re-seals all files
⚠️ Old key and new key produce different encryption. All files must be re-sealed.
🗑️
Reset / Start Over
Settings
  1. Settings → "Reset TouchFS"
  2. Confirmation dialog
  3. All managed files unsealed
  4. Key deleted from Keychain
  5. Config cleared → back to onboarding
💻
Install CLI
Settings
  1. Settings → "Install CLI"
  2. Symlinks bundled binary to /usr/local/bin/touchfs
  3. May need admin password
  4. touchfs works in any terminal
📌
Menu Bar
Lifecycle
  1. Click shield icon in menu bar
  2. "Protecting N files" (status)
  3. "Open TouchFS" → focus window
  4. "Quit TouchFS" → graceful shutdown
🔄
Open at Login
Settings
  1. Settings → toggle "Open at Login"
  2. App launches on login via SMAppService
  3. Sits in menu bar, mount starts
  4. Files always protected when Mac is in use
